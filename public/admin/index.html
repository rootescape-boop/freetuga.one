Вход в админку выполняется по токену GitHub. После входа можно создавать материалы, загружать обложки и публиковать изменения — они попадут в репозиторий и сайт пересоберётся автоматически. Токен создаётся в GitHub → Settings → Developer settings → Fine-grained tokens с доступом к репозиторию rootescape-boop/freetuga.one и правами Contents: Read and write.
