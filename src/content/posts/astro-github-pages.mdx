У этого сайта нет базы данных, сервера и панели администратора в привычном смысле. Есть репозиторий, генератор статических страниц и GitHub Actions. Такой набор звучит скромно, но закрывает почти всё, что нужно личному блогу.

## Контент — это файлы

Каждая статья — отдельный `.mdx`-файл с frontmatter: заголовок, описание, дата, обложка, теги, список видео. Astro читает папку `src/content/posts` через content collections и проверяет поля по схеме Zod. Если забыть дату или перепутать тип видео — сборка упадёт с понятной ошибкой, а не сломает страницу в проде.

```yaml
title: Как этот сайт собирается
description: Короткое описание для карточки и поисковиков
date: 2026-10-28
tags: [технологии, astro]
videos:
  - platform: youtube
    id: aqz-KE-bpKQ
```

Такой подход даёт бесплатные бонусы: историю изменений в git, поиск по тексту, ревью через pull request и возможность откатить любую правку одним коммитом.

## Сборка

Astro превращает файлы в обычный HTML и CSS. На выходе — папка `dist` без клиентского роутера и лишнего JavaScript. Тяжёлые вещи вроде плееров и поиска подгружаются только тогда, когда нужны.

Дальше GitHub Action собирает сайт при каждом пуше в `main`:

1. устанавливает зависимости;
2. запускает `astro build` и индексацию Pagefind;
3. публикует артефакт на GitHub Pages.

Обычно весь цикл занимает меньше двух минут. Можно править статью с телефона и через минуту видеть её на сайте.

## Админка без сервера

Админка живёт по адресу `/admin` и представляет собой статическую страницу с Sveltia CMS. Она общается с GitHub API напрямую: читает файлы, загружает картинки в `public/uploads`, сохраняет изменения коммитом.

Авторизация — по личному токену GitHub с доступом только к этому репозиторию. Токен хранится в браузере, поэтому такой вариант подходит для личного блога, но не для редакции из десяти человек. Для команды понадобился бы OAuth-прокси и роли.

## Что в итоге

Стек получился скучным — и это комплимент. Нет серверов, которые падают, нет базы, которую надо бэкапить, нет зависимости от чужой платформы. Есть текст, git и несколько сотен строк кода. Для блога этого достаточно.
