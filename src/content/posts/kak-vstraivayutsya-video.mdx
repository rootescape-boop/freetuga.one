Встроенное видео — одна из самых дорогих вещей на странице. Один iframe с YouTube тянет несколько сотен килобайт скриптов, устанавливает cookies и начинает грузить сегменты видео ещё до того, как вы решили что-то смотреть. Если в материале три ролика, счёт идёт на мегабайты.

## Сначала — картинка

Решение простое: показываем постер и кнопку, а плеер создаём в момент клика. Выглядит как обычное видео, весит как картинка.

```html
<div class="video" data-platform="youtube" data-id="aqz-KE-bpKQ">
  <img src="https://i.ytimg.com/vi/aqz-KE-bpKQ/maxresdefault.jpg" alt="" />
  <button class="video__play" aria-label="Смотреть видео">▶</button>
</div>
```

По клику подменяем содержимое блока на iframe с `autoplay=1`. YouTube отдаём через `youtube-nocookie.com`, Rutube — через `rutube.ru/play/embed/`, VK — через `vk.com/video_ext.php`. Никаких запросов к видеосервисам до действия пользователя.

## Что это даёт

- **Скорость.** Постер — это один файл, часто уже в кеше браузера. Основной поток страницы не блокируется.
- **Приватность.** До клика YouTube, Rutube и VK не узнают о визите.
- **Контроль вёрстки.** Обложку можно кадрировать, наложить подпись и подогнать под сетку — iframe такой свободы не даёт.
- **Меньше сюрпризов.** Плеер не подгружает рекомендации и не уводит читателя в бесконечную ленту.

## Rutube: превью из API

У YouTube предсказуемый адрес постера. У Rutube обложку отдаёт API видео, поэтому её удобно забирать на этапе сборки:

```js
const res = await fetch(`https://rutube.ru/api/video/${id}/`);
const { thumbnail_url } = await res.json();
```

Если запрос не удался, остаётся аккуратный градиентный плейсхолдер — страница всё равно выглядит цельно. Такие вещи лучше делать на сборке, чем в браузере: посетителю не нужно ждать ещё один запрос.

## VK Видео: oEmbed и ручная обложка

У VK Видео адрес ролика выглядит как `vk.com/video-12345678_456239017`. На сборке обложку можно запросить через oEmbed:

```js
const url = encodeURIComponent('https://vk.com/video-12345678_456239017');
const res = await fetch(`https://vk.com/oembed?url=${url}&format=json`);
const { thumbnail_url } = await res.json();
```

Если сеть недоступна или ролик закрыт, остаётся градиент. Для важных материалов лучше указать обложку вручную в поле `poster` — тогда предсказуемый вид не зависит от стороннего сервиса.

## Ссылка вместо плеера

Отдельный сценарий — когда видео не главное, а иллюстрация к тексту. Тогда достаточно обычной ссылки на ролик: скрипт сам превратит её в фасад с постером. Не нужно помнить синтаксис компонентов, а читателю — открывать новую вкладку.

Главное правило: видео должно появляться там, где оно помогает тексту, а не для того, чтобы «оживить» страницу. Один уместный ролик лучше пяти автоплеев.
