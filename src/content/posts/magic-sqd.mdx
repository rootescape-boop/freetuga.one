Magic SQD — отдельный проект, установщик приложений для мультимедиа-систем китайских автомобилей. С его помощью ставятся архивы FreeTUGA: `Magic_SQD_v3`, v4 и последующие версии.

## Возможности

- Каталог «марка → модель → модификация» с пошаговой инструкцией под конкретное ГУ.
- Подключение по ADB через USB или Wi-Fi, установка с флешки, права ADB по QR-коду, telnet/UART там, где ADB скрыт.
- Набор приложений под систему, выдача разрешений и дополнительные действия в одном окне.
- Проверка APK до установки: процессор, версия Android, подпись.
- Версии для Windows 10/11, macOS (Apple Silicon и Intel) и Android.
- Автообновление программы.

## Как это связано с FreeTUGA

Архивы проекта содержат этапы установки и набор приложений для поддерживаемых головных устройств. Magic SQD берёт на себя рутинную часть: подключение, выбор файлов, установку и разрешения.

Порядок первой установки описан в [ЧАВО](/faq/kak-ustanovit-freetuga), состав версии — в разделе [«Релизы»](/releases).

## Где взять

Актуальную версию публикует автор проекта Magic SQD на своём сайте. Для FreeTUGA используйте архив, который приложен к релизу в сообществе: версия установщика и профиль ГУ должны совпадать.
