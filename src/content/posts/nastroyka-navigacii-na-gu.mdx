Для корректной работы навигатора и антирадара ГУ нужны данные о местоположении. Их можно получить двумя основными способами — с телефона по Wi-Fi или подключив GPS-модуль к USB-порту.

## Способ 1. Раздача с телефона

- **Car GNSS Bridge** (на ГУ) и **Компаньон** (на Android-телефоне). Приложение умеет работать с несколькими приёмниками навигационных данных и способно вести по дорогам даже при потере спутников.
- **GNSS Share** (на ГУ — клиент, на телефоне — сервер).

## Способ 2. GPS-модуль по USB

Подключите GPS-модуль к USB-порту ГУ. Такой модуль настраивается на компьютере, после чего подключается к ГУ.

## Как сделать, чтобы приложения «видели» координаты

Чтобы GPS работал корректно, укажите приложение как **«Источник фиктивных местоположений»**:

- через **GSettings**;
- или вручную командой:
  ```
  appops set имя_пакета mock_location allow
  ```

## Нюансы Car GNSS Bridge

- При первом запуске приложение само проводит через настройки.
- В настройках можно выбрать свою машину для более точной работы.
- Чтобы вело без спутников, проверьте, что в режиме «только алгоритм» показываются скорость и курс.
- Если возникают проблемы — лучше снять диагностику и отправить её автору приложения.
